## 개요
웹캠에서 사용자 얼굴을 검출하고, 양 볼에 작업 디렉토리 내 햄스터 이미지(.png)를 합성하는 MediaPipe 파이썬 프로그램

<br>

## 실습 환경
macOS

<br>

## 사전 세팅
1. 작업 디렉토리명: haem-and-me
2. 작업 디렉토리 경로: (09.11 기준) 로컬 환경에 종속
- 개선 필요: 개인 환경에 의존하지 않는 경로로 변경
3. 대상 이미지: 양 볼에 합성할 햄스터 이미지
- 파일명: `haem.png`
- 위치: `./haem.png`

<br>

## 실습 진행
#### ❶ ChatGPT 웹 프롬프트
```
1. 웹캠에서 얼굴을 검출, 양 볼에 '경로'의 'haem.png'를 합성하는 MediaPipe 파이썬 프로그램
2. TASK.md 작성
3. README.md 작성
```

<br>

#### ❷ Codex 프롬프트
```
1. `작업 디렉토리 경로`로 이동
2. TASK.md에 따라 지시된 범위 안에서 작업
3. 기존 파일을 먼저 점검하고 오류가 있을 때만 최소 수정
4. README.md를 실제 결과에 맞춰 갱신하고 미검증 항목을 명시
```
<br>

#### ❸ 프로그램 실행
- 터미널에서 대상 디렉토리로 이동, 아래 명령 실행하여 결과 확인
```
.venv/bin/python main.py
```
<br>

#### ❹ 실행 결과
- 웹캠 정상 실행
- 얼굴 검출 확인
- 양 볼에 대상 이미지 합성 확인

<br>

## 개선 필요
- 작업 디렉토리, 이미지 경로가 로컬 환경에 종속
- 범용적으로 실행 가능하도록 상대 경로 등으로 변경 필요

<br>
