## 개요
정해진 시간에 사용자가 지정한 키워드의 Google News 검색 결과를 가져와 기사 제목과 링크를 Gmail로 전송하는 자동화 프로그램

<br>

## 실습 환경
- macOS
- Google Apps Script

<br>

## 실습 진행
#### ❶ ChatGPT 웹 프롬프트
```
아래 지시를 따르는 Google Apps Script 코드를 작성

1. 사용자가 정한 키워드로 구글 뉴스에서 최신 기사 제목과 링크 가져오기
2. 가져온 결과를 사용자 Gmail로 전송
3. 키워드는 코드 맨 위에서 변경 가능
```

<br>

#### ❷ Google Apps Script 프로젝트 생성 및 스크립트 수정
1. Google Apps Script(https://developers.google.com/apps-script?hl=ko) 접속 및 프로젝트 생성
2. 생성된 스크립트 코드 붙여넣기 후 상수값 수정
- `KEYWORD` = 원하는 키워드 / `RECIPIENT_EMAIL` = 보낼 이메일

<br>

#### ❸ 스크립트 실행
- 스크립트 저장 후 상단 `실행` 클릭
- 하단 실행 로그에서 `실행이 시작됨`, `실행이 완료됨` 알림 확인

<br>

#### ❹ 트리거 적용
- 정해진 시간에 메일을 전송하기 위해 트리거 적용
- 좌측 메뉴에서 `트리거` 클릭 > 트리거 추가
- 세부 항목 설정 후 적용 (ex. 매일 아침 메일을 받기 위해 `오전 7시 ~ 오전 8시 사이`로 시간 설정)

<br>

#### ❺ 실행 결과
- 설정한 시간에 키워드에 맞는 메일 수신 확인

<br>
